# Paradise Nursery

Paradise Nursery is a houseplant e-commerce web application built with React and Redux Toolkit.

## Project name
Paradise Nursery

## Description
An online nursery where users can browse houseplants by category, add them to a shopping cart, adjust quantities, and review the total cost before checkout.

## Features
- Landing page with the company name and a "Get Started" button
- About Us section describing the company
- Product listing with at least six plants in each of three categories
- "Add to Cart" buttons that disable after use and update the cart icon count
- Shopping cart page with quantity controls, per-item totals, overall total, delete, checkout ("Coming Soon") and continue shopping
- Navbar with Home, Plants and Cart links on both pages

## Tech stack
React, Vite, Redux Toolkit, React-Redux

## Run locally
npm install
npm run dev
